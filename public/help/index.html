Using SkillTube

Find an AI resource

Browse public developer and listing pages or search by name and topic. Read a listing carefully, check its licence and review its repository before using it. SkillTube does not host repository files.

Publish a listing

Sign in with an eligible GitHub account, choose your country, and publish a public repository you own. Add a clear description and all required topic and detail tags. AI skills are the main focus; MCP servers, datasets, databases, prompts, agents, AI tools and guides are welcome too.

Manage your account

Use the app's My listings and Settings pages to edit or delete listings, update your profile, manage your country setting, or delete your account. Some actions have limits or cooldowns displayed in the app.

Need more help?

See the FAQ, Community Guidelines and Security page. For account or general support, contact Let's Code India.
