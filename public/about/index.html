About

A discovery layer for AI resources

SkillTube is a free, open-source directory built by Let's Code India. AI skills are the main focus, and developers can also list MCP servers, datasets, databases, prompts, agents, workflows, tools, CLIs, SDKs, plugins, model configurations and guides that live in public GitHub repositories.

GitHub is where developers keep code, history, issues and licences. SkillTube adds a curated discovery layer: structured cards, clear descriptions, 39 tags, public developer channels, activity signals and badges. A listing links back to its developer's repository; SkillTube does not host the resource files.

Readable pages, human profiles

Public skill and developer pages are server-rendered, include Markdown twins and structured metadata, and are listed in the sitemap. AI crawlers can find repositories on GitHub, but a SkillTube channel gives them your profile and every listing as clean, structured, complete pages.

Built with care

The app uses plain HTML, CSS and JavaScript. It is designed to work without a build step, stays free to use, and does not run ads or analytics trackers. Repository ownership is checked through GitHub, and reports include a developer response flow.
