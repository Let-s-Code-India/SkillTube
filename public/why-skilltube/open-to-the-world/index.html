Open to the world

SkillTube is a free, open-source community layer from Let's Code India for developers everywhere.

2026-11-24
communityopen source

SkillTube is a free, open-source community layer from Let's Code India. It is open to developers everywhere. AI skills are the main focus, and the directory also welcomes MCP servers, datasets, databases, prompts, agents, workflows, tools and guides that live in public GitHub repositories.

The project is designed so people can participate without adopting a particular framework or moving their work. Developers keep their repositories, history, issues and licences on GitHub. SkillTube provides structured listings, topic tags and developer channels that help visitors browse the work. The directory does not host the resource files, and each developer remains responsible for their own repository and licence.

Open-source software makes it possible to inspect how the service works, suggest improvements and contribute changes. The project publishes its policies and technical documentation so contributors can understand the rules for accounts, listings, reports and community activity. A public codebase is an invitation to collaborate, not a promise of unlimited support or uninterrupted service.

The service is intended to remain free to use. It relies on open-source tools, free service plans and community effort rather than subscriptions or paid access. Providers can have outages, and features may change as the project grows. We aim to describe those limits plainly and keep important product rules easy to find.

An open directory is useful only when people with different backgrounds can take part. Developers should be able to share a focused AI skill, a dataset, an MCP server or another resource without needing a large audience already. Visitors should be able to read a clear description, find its creator and follow the link back to the original repository.

The team also has responsibilities: maintain a clear reporting process, protect private account information, publish contact routes and explain how moderation works. Those details are covered in the legal pages and help content. They apply consistently to everyone who uses the service.

If you build an AI resource, you can share it through a listing and your developer channel. If you are exploring what others have made, review the project and its licence before using it. SkillTube aims to be a practical, welcoming discovery layer that developers everywhere can inspect, use and help improve.
