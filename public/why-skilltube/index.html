Why SkillTube

Why we need a discovery layer for AI resources

AI skills are our main focus, and useful MCP servers, datasets, databases, prompts, agents and AI tools belong here too. These articles explain the choices behind the directory without hype.

discovery · community

Why we built SkillTube

Useful AI resources are scattered across repositories; SkillTube adds one free, structured place to discover them.

2026-11-24

discovery · AI skills

Finding a good AI skill is harder than writing one

Names, descriptions, tags and activity signals help people compare projects beyond repository names.

2026-11-24

GitHub · ownership

Every listing lives in its own public GitHub repository

Ownership, history, licence and issues stay with the developer; SkillTube provides a discovery card and link.

2026-11-24

free · open source

Free for developers and users, with no credit card

SkillTube is designed around open-source software and free service plans, with no paid APIs or subscriptions.

2026-11-24

trust · GitHub

Owners are checked against GitHub

GitHub sign-in and recurring repository checks help keep listings tied to their owners.

2026-11-24

catalog · maintenance

Dead listings clean themselves up

The catalog job checks repositories repeatedly and removes listings after consecutive failed checks.

2026-11-24

datasets · databases

AI needs data, not only skills

Datasets, vector stores and databases deserve the same clear discovery as prompts and agents.

2026-11-24

discovery · fairness

Small developers get a fair chance

A mixed-strength search approach is intended to give useful new listings a path to discovery.

2026-11-24

badges · trust

Badges and ticks you cannot buy

SkillTube awards badges through published activity rules; audience ticks are not paid verification.

2026-11-24

safety · reports

Reporting that is fair to both sides

Reports allow a developer response, preserve reporter privacy and hide serious listings while reviewed.

2026-11-24

privacy · data

We store as little as possible

SkillTube does not store IP addresses or run analytics; country stays private and minimal records expire.

2026-11-24

accounts · safety

Why SkillTube is 18+

The service requires adult users and GitHub accounts that meet the age requirement.

2026-11-24

community · open source

Open to the world

SkillTube is a free, open-source community layer from Let's Code India for developers everywhere.

2026-11-24

open source · transparency

Open source, with the rules in public

MIT-licensed code, public docs and an error-code table make the project easier to inspect.

2026-11-24

accessibility · performance

Light, fast and works on a phone

Native web technologies and server-rendered public pages keep the experience straightforward on small devices.

2026-11-24

getting started · publishing

Start in five minutes

A short path from GitHub sign-in to a tagged listing and a shareable developer channel.

GitHub · discovery

GitHub already exists. Why SkillTube?

GitHub keeps the code; SkillTube adds structured discovery, comparison and developer channels.

Be found by people and by AI assistants
