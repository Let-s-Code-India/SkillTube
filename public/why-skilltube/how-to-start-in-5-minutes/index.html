Start in five minutes

A short path from GitHub sign-in to a tagged listing and a shareable developer channel.

2026-11-24
getting startedpublishing

Starting with SkillTube is meant to be a short sequence rather than a migration. You do not move your code or upload the project files. You sign in with GitHub, complete the account checks and choose the country where you currently live. Country is private and is used only for aggregate counts.

To publish, choose a public repository that belongs to your signed-in GitHub account. Give the listing a concise name and short description, then explain its purpose and how someone can use it. AI skills are the primary focus, but MCP servers, datasets, databases, prompts, agents, tools and guides can use the same listing form.

The tag picker asks for three topics, nine subtopics and 27 detail tags. These tags help people find projects by area and intended use. Choose them accurately; adding unrelated words makes search less useful. The listing type is a description aid, not an extra backend field or a separate category system.

Before submitting, check that the repository is public and the description is truthful. Make the licence clear in the repository, include setup requirements and examples, and mention limitations. The publishing service checks repository ownership and uses the GitHub token captured during sign-in. It does not guarantee that the project is safe or correct.

After publication, open the listing and review how it appears to someone who has not seen the code. Your developer channel gathers your public listings and can be shared as a profile link. You can update your descriptions and tags through My listings, subject to the edit cooldown shown in the app.

A first listing is only the beginning. Keep the repository maintained, respond to reports and use the dashboard to understand activity. If you are unsure about a field or policy, consult the FAQ and publishing help before submitting.

The time to publish will depend on whether the repository is ready and whether account checks are complete; five minutes is a quick-start goal, not a guarantee. A clear README, a valid licence and a tested public repository make the process smoother. If the form reports a limit or validation problem, read the friendly message and correct the listing rather than trying to bypass the restriction.
