Security

Last updated: 24 November 2026

Report a vulnerability privately: email any of the three contact emails with subject "Security", or use the private vulnerability reporting of the SkillTube repository (GitHub → Security → Report a vulnerability) and the organisation's security policy. Include steps to reproduce, impact and affected URL. Please do not publish details until we fix it, do not access other users' data, do not run denial-of-service tests, and do not spam. We acknowledge within 72 hours and aim to fix serious issues quickly. This is a volunteer project and we cannot pay bounties, but we will credit you if you wish.

How we protect SkillTube: closed database tables with row-level security; only vetted functions callable from the website; server-side admin checks; strict Content Security Policy with no inline scripts; sanitised markdown and SVG; no secrets in the browser; no IP storage; automatic catalog checks every 6 hours; minimal data kept and purged after 180 days.

.well-known/security.txt must contain: Contact (three mailto lines + the GitHub security advisory URL), Expires (one year ahead), Preferred-Languages: en, Canonical: the site URL + /.well-known/security.txt, Policy: the Security page URL.
