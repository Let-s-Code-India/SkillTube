Contacting us

Contact Let's Code India for account support, grievances, copyright notices or other questions about SkillTube.

Choose one contact route

Email one of these addresses; one email is enough. Do not send the same request to all three at once.

  • ayushgiri.ai.21@gmail.com
  • ayushgiri.25@icloud.com
  • ayushgiri.dev1@outlook.com

For copyright or takedown requests, use the GitHub takedown_request issue template.

Include useful details

Include your GitHub username, the page URL, the date and time, a short description of the issue, and the outcome you want. Use English so the team can review your request.

Do not send passwords, access tokens, private keys or personal identity documents.

Grievances and response times

The Grievance Officer is Ayush Giri, Founder of Let's Code India, India. Grievances are acknowledged within 72 hours and are targeted for resolution within 30 days. The same published acknowledgement and resolution targets apply to appeals; a separate response-time guarantee is not stated for general support.

For appeals, include Appeal in the email subject. See Removals and appeals. For a security issue, use the Security page and its private reporting route.
