Changelog

Notable changes to SkillTube are documented here. Dates refer to shipped repository changes; backend availability may depend on owner deployment.

[1.0.1] - 2026-11-25

Changed

  • Added ten public Markdown-authored documentation guides and Markdown twins.
  • Linked official Let's Code India attribution from public and Worker-rendered footers.
  • Added complete app, 404 and offline Open Graph metadata and PWA install icons.
  • Improved 375px and 900px layouts, touch targets and comment/reply readability.

Checks

  • Added responsive and image-file-signature checks to repository validation.

[1.0.0] - 2026-11-24

Added

  • Public search, topic pages, listing and developer profiles.
  • Publishing and listing management, images, community features, reports, admin tools, badges, dashboards and ranking widgets.
  • Legal policies, FAQ and public help content.

Security

  • Public pages do not expose Source links or private country data.
  • Browser access to Supabase is routed through documented functions.
