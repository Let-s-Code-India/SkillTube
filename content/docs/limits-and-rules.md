# Limits and rules

SkillTube uses activity limits and cooldowns to keep publishing and community actions manageable. The app shows an error when an action is unavailable.

Last updated: 2026-11-25

## Limits

| Area | Limit |
| --- | --- |
| GitHub account age | At least 3 months to sign up |
| Publish slots | Start at 25; additional slots grow with views, followers and invites |
| Listing edits | Once every 10 days |
| Channel profile edits | Once every 30 days |
| Country changes | Once every 90 days |
| Restore a deleted listing | Within 12 hours |
| Counted views | One view per person per listing every 6 hours |
| Comment length | 200 characters |
| Reply length | 100 characters |
| Comments and replies | 30 combined per 24 hours |
| Comment and reply on one listing | One comment and one reply per listing per 24 hours |
| Pinned comments | Up to 3 |
| Unpinned comment lifetime | 5 days; pinned comments stay |
| Stars | Up to 300 |
| Follows | Up to 200 |
| Reports | 10 per 24 hours and one report per target per 24 hours |

## Ranking

The weekly ranking needs your first listing to be at least 3 months old. It shows the top 50 developers in bands of ten; your profile shows your best band.

See the [badge catalog](/badges/) for badge information. This guide does not repeat the badge list.
