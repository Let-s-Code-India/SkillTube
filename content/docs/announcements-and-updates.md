# Announcements and updates

Announcements share news from the SkillTube team. Updates help you follow new activity from developers you follow.

Last updated: 2026-11-25

## Team announcements

Announcements appear in a pinned banner and on the **Announcements** page in the app. At most one announcement is posted per day. Open the page to read current and earlier announcements.

## Updates from followed developers

The Updates page groups three kinds of activity:

- **New listing** — a developer publishes a listing.
- **Edited listing** — a developer changes a listing.
- **New version** — a developer announces a new version.

A blue dot marks new activity for each followed developer. Repeated items are collapsed into a notice such as “and more”. A red dot is used for report notices and new badges.

## Announce a new version

Open **My listings**, choose **I released a new version**, enter an optional note and submit it. The note can be up to 140 characters. The update appears in your followers' feed.
