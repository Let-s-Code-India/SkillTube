# Changelog

All notable changes to SkillTube are documented here.

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)
and [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-24

### Added

- Public discovery for AI skills and related AI resources.
- GitHub sign-in, publishing, profile management and repository verification.
- Search, developer channels, topics, community features and activity feeds.
- Reports, moderation tools, badges, rankings and account dashboards.
- Public help, FAQ, legal and project information pages.
- Server-rendered public pages, sitemap and crawler-readable metadata.

### Changed

- Finalized public content, documentation and repository quality workflows.

### Fixed

- Added automated schema, static-link and generated-content checks.
# 1.1.0

- Unified the static, SPA, and Worker frontend around the SkillTube design system.
- Added seven theme choices, system theme following, and the shared theme boot and picker.
- Restyled listing cards, navigation, dashboard charts, and responsive layouts.
